# SALATI FIRST – صلاتي أولاً

## ما الذي يعمل في هذه النسخة؟
- حساب مواقيت الصلاة بطريقة الهيئة المصرية العامة للمساحة عبر مكتبة Adhan.
- تحديد الموقع الحالي بإذن المستخدم، مع إحداثيات افتراضية لمدينة بورسعيد عند رفض الإذن.
- عد تنازلي للصلاة القادمة أثناء فتح التطبيق.
- شاشة تذكير عند دخول نافذة الصلاة أثناء عمل التطبيق.
- تسجيل الصلوات اليومية محلياً.
- التقاط صورة اختيارية للسجادة بالكاميرا وحفظ مسارها محلياً.
- خدمة Accessibility اختيارية تعيد المستخدم إلى التطبيق عند فتح تطبيق آخر أثناء تشغيل الوضع الصارم.

## مهم جداً بخصوص الوضع الصارم
خدمة إمكانية الوصول لا تغلق التطبيقات ولا تمنع فتحها على مستوى نظام التشغيل. هي تراقب انتقال النوافذ وتعيد فتح SALATI FIRST خلال أول 60 دقيقة بعد موعد الصلاة غير المسجلة. إعدادات النظام والتطبيقات الأساسية مستثناة لتجنب تعطيل الهاتف. يمكن للمستخدم إيقاف الخدمة من إعدادات أندرويد.

هذه نسخة أولية قابلة للبناء والاختبار وليست قفلاً أمنياً أو نظاماً يمنع التجاوز نهائياً. مهم: يجب فتح التطبيق مرة واحدة يومياً لتحديث مواقيت اليوم. التذكير الدقيق عندما يكون التطبيق مغلقاً تماماً، وإعادة جدولة المنبهات بعد إعادة تشغيل الهاتف، يحتاجان إضافة AlarmManager / إشعارات بملء الشاشة واختبارهما على جهاز حقيقي. خدمة Accessibility لا تضمن فتح شاشة الصلاة إذا كان النظام قد أوقف التطبيق.

## خطوات البناء
1. أنشئ مشروع Flutter جديداً باسم `salati_first`.
2. استبدل `pubspec.yaml` و`lib/main.dart` بالملفين الموجودين هنا.
3. استبدل ملف `android/app/src/main/AndroidManifest.xml`.
4. انسخ ملفات Kotlin وملف XML وملف strings إلى المسارات نفسها.
5. شغّل `flutter pub get`.
6. ابنِ APK باستخدام `flutter build apk --release`.

## متطلبات Android
- minSdk 24 أو أحدث.
- Kotlin package في MainActivity هو `com.example.salati_first`. إذا غيّرت applicationId، غيّر package في ملفات Kotlin واسم الحزمة المستخدم في PrayerAccessibilityService.
- في حال كان مشروعك يستخدم `build.gradle.kts` أو namespace مختلفاً، حافظ على namespace متوافق مع مسار ملفات Kotlin.

## الاختبار
- افتح التطبيق واسمح بالموقع.
- فعّل الوضع الصارم، ثم فعّل خدمة "صلاتي أولاً" من إعدادات إمكانية الوصول.
- جرّب فتح تطبيق غير أساسي. ستتم إعادتك إلى SALATI FIRST طالما الخدمة تعمل والوضع الصارم مفعّل.
- جرّب تسجيل الصلاة والتقاط صورة اختيارية.
